
# Clínica IA — Sistema de Autoatendimento Inteligente

O **Clínica IA** é uma versão beta de um sistema de autoatendimento inteligente para clínicas médicas, desenvolvido como projeto acadêmico.  
A proposta do projeto é simular um assistente virtual capaz de auxiliar pacientes em processos como cadastro, login, atendimento inicial, cadastro de dependentes e agendamento de consultas ou exames.

## Objetivo do projeto

O objetivo principal é aplicar conceitos de desenvolvimento web, autenticação, banco de dados em nuvem e integração com inteligência artificial em um sistema prático voltado para o setor da saúde.

A aplicação busca oferecer uma experiência simples e intuitiva para o paciente, permitindo que ele interaja com um assistente virtual para obter suporte durante o atendimento e o processo de agendamento.

## Funcionalidades

- Cadastro de usuários
- Login com autenticação
- Chat com assistente virtual
- Cadastro e visualização de dependentes
- Estrutura inicial para agendamento de consultas e exames
- Integração com banco de dados em nuvem
- Base para envio de confirmação de consulta por e-mail
- Planejamento para confirmação via WhatsApp

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Cloud Firestore
- EmailJS
- API de Inteligência Artificial
- Git e GitHub

## Funcionalidades em desenvolvimento

- Implementação de uma planilha de horários disponíveis para ser usada como base pela IA nos agendamentos
- Envio automático de confirmação de consulta por WhatsApp ou e-mail para o paciente e para a clínica
- Histórico completo de agendamentos
- Melhorias na responsividade
- Melhorias na segurança das integrações
- Criação de um backend mais robusto para proteger chaves e APIs
- Validações mais avançadas nos formulários
- Tratamento de erros mais completo

## Status do projeto

🚧 Projeto em desenvolvimento — versão beta.

Este projeto ainda está em fase de testes e melhorias. Algumas funcionalidades podem ser ajustadas, substituídas ou aprimoradas nas próximas versões.

## Aprendizados

Durante o desenvolvimento deste projeto, foram trabalhados conceitos como:

- Estruturação de páginas com HTML
- Estilização e responsividade com CSS
- Manipulação de DOM com JavaScript
- Autenticação de usuários
- Integração com Firebase
- Armazenamento de dados no Firestore
- Integração com IA
- Organização de código em múltiplos arquivos
- Versionamento com Git/GitHub

## Observação

Este projeto foi desenvolvido com fins acadêmicos e de aprendizado.  
Não deve ser utilizado em ambiente real de produção sem melhorias de segurança, validação, privacidade de dados e proteção das chaves de API.
